How overlap is measured

Ingredient overlap = number of shared ingredient IDs ÷ number of distinct ingredient IDs across both dishes (Jaccard similarity). Exact means both dishes contain precisely the same ingredient IDs, regardless of quantities. All ingredients, including seasonings, are included; there is no fuzzy name matching.

Quantity overlap = sum of the smaller gram amount for each shared ingredient ÷ sum of the larger gram amount across all ingredients. It breaks ties between dishes with the same ingredient overlap. “Same amounts” requires an exact ingredient set and no more than 0.1 g difference per ingredient. Repeated ingredient IDs within a dish are summed.

The comparison covers official RGB split dishes with ingredient metadata, including dishes with no downloaded photo. All exact ingredient-set pairs are retained, plus the top 12 overall matches and top 12 matches with training photos per test dish. The photo filter requires photos for both dishes; all-metadata totals remain available under “All dishes”. This is recipe overlap evidence; ingredient overlap alone does not establish data leakage. Common ingredients can occur in independent dishes.
